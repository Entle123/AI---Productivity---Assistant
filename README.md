# AI-Powered Productivity Assistant

## Project Description
A functional prototype demonstrating 5 AI features for workplace productivity.

## Features
1. **Smart Email Generator** - Draft professional emails with tone control
2. **Meeting Notes Summarizer** - Extract key points, actions, and deadlines  
3. **AI Task Planner** - Prioritize tasks and suggest schedules
4. **AI Research Assistant** - Get insights and summaries on work topics
5. **AI Chatbot Interface** - Answer workplace questions instantly

## How to Use
1. Open `index.html` in your browser
2. Click each feature in the sidebar to see examples

## Disclaimer
*AI-generated content may require human review before use.
